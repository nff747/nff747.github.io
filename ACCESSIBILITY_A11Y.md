# Accessibility (a11y) & Keyboard Navigation Hierarchy

### Global Keyboard Navigation
- Mapped hotkeys (`[H]`, `[Space]`, `[R]`, `[1-5]`) for HUD toggle, simulation pause, and presets.
- Fully accessible keyboard focus traps with visible high-contrast focus rings.

### Screen Reader ARIA Tree
- Injected semantic ARIA landmarks and live regions for dynamic telemetry readouts.
- Synchronized 3D WebGL viewport states with accessible DOM text representations.
