## ⚡ Features

- **Real-Time 3D Viewport**: Built on Three.js & `@react-three/fiber` with custom shaders, dynamic lighting, and orbital controls.
- **Cyberpunk Narrative HUD**: Interactive status screens, diagnostic logs, and glitch animation effects.
- **Synthesizer Spatial Audio**: Web Audio API cybernetic sound effects (`cyberAudio.ts`) triggered on user interactions.
- **Interactive Case Studies**: Deep-dive showcases for flagship deep-tech engines (`splat-bvh-core`, `auto-rig-web`, `aerocache`, `helix-lsm`, etc.).
- **Ultra-Responsive**: Fully responsive design leveraging Tailwind CSS and Framer Motion.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router, Static HTML Export)
- **3D Engine**: Three.js, React Three Fiber (R3F), `@react-three/drei`
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS
- **Deployment**: GitHub Pages (`nff747.github.io`)
