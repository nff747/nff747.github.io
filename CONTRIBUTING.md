# Contributing to Developer Portfolio WebGL

Thank you for contributing to **Developer Portfolio WebGL** (`nff747.github.io`), an interactive 3D portfolio powered by Next.js, React Three Fiber, Three.js, and Tailwind CSS.

## Development Setup

```bash
npm install
npm run dev
```

Build the static output for GitHub Pages:

```bash
npm run build
```

## How to Submit Changes

1. Fork the repo and create a feature branch (`git checkout -b feat/my-feature`).
2. Verify that `npm run build` succeeds cleanly without type errors.
3. Open a Pull Request.
